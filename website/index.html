A small routine.
A lot of repositories.

Dependency updates, documentation passes, code reviews. The work repeats; writing the task doesn’t have to.

02 / Your repositories, your control

Local by design.
Explicit by default.

CodeConvoy coordinates the tools already on your machine. You choose the repositories, the backend permissions, and how results move forward.

Read the execution and safety details ↗
↳ Review before running
Check branches and existing changes before launch. CodeConvoy prevents its jobs from writing to the same or nested working tree concurrently.
↳ Room to work in isolation
Optional worktrees start from the committed HEAD you reviewed. Results stay available for inspection, with explicit Apply and Discard actions.
↳ Your CLI stays in charge
Use each agent’s own configuration and authentication. CodeConvoy adds no provider login or credential store; your chosen CLI’s data policy still applies.
